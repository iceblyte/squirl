退出回收的三条路径

AC9 INV-2
路径触发动作保证
手动停止用户在日志面板点「停止」结束整个进程树（Job Object / setsid）exit 143，无残留子进程
应用退出关闭窗口 / 从托盘退出遍历 run 注册表，逐个结束退出前等待 ≤ 2 秒，超时强杀
后端崩溃Rust 主进程异常终止Windows 由 Job Object 随句柄关闭回收；Unix 使用 prctl(PDEATHSIG)外部终端会话完全不受影响（INV-2）
两条路径不得混同 外部终端里的进程归终端所有，Squirl 只负责唤起、不接管；只有应用内启动的进程才进入 run 注册表与回收流程。
