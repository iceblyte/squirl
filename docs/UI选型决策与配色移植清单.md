## 1. 决策摘要

1. **UI 基线采用 `prototype-tr`**（纸感暖白 · 橡果棕 · 左侧栏）。理由：三套中唯一同时满足「最终版需求（UI 文案中文，见 commit `c525774`）」与「最高原型完成度（交互保真、明暗双主题、F6 覆盖、统一外壳）」的一套。
2. **配色处理移植 `prototype-wb`**：中性阶去棕味（冷灰阶）、主按钮与选中态改近黑、wash 收敛使用面、画布顶部加橡果光晕、圆角收紧。即「**tr 的结构 + wb 的观感**」。
3. `prototypes-zc`（暗色橡木）不作为基线：UI 文案为英文（依据已被推翻的旧版需求）、MVP 页面缺 F6 退出回收场景、仅暗色实现。其扩展功能形态页（P1/P2/P3）在实现扩展期作为主要参照。

> 对比评审的证据与截图：`.screenshots/prototype-compare/`（18 张，覆盖三套核心页面、tr 暗色主题与 900px 窄窗实测）。

## 3. 配色差异诊断（为什么 wb 观感更佳）

两套配色同源（画布 #F2F1EE、橡果棕 #9C5A32、moss/brick/amber 语义色几乎一致），感知差异来自五处：

1. **中性阶温度（主因）**：tr 的灰阶带棕味（`--ink-2 #59544B`、`--ink-3 #8B857A`、`--line #E2DDD3`），大面积铺开偏「牛皮纸」；wb 为去饱和纯暖灰（`#5C5952` / `#98938A` / `#E4E1DB`），偏「暖白纸」。灰阶占界面约 95% 面积，决定整体气质。
2. **主按钮颜色归属**：tr 主按钮/侧栏选中项为橡果棕实底；wb 主按钮为近黑 `#171614`，橡果棕仅出现在 hover 与状态点——符合其「单屏强调色面积 ≤ 3%」纪律，整屏更安静利落。
3. **wash 用量**：tr 把 `#F6EDE4` 铺在信息横幅、运行按钮、hot 标签等多处；wb 只用于极小 chip 与焦点环。
4. **顶部光晕**：wb 画布顶部有一层 `radial-gradient(1200px 500px at 50% -200px, rgba(156,90,50,.05), transparent 70%)`，白卡更有浮起感。
5. **圆角**（非颜色但影响观感）：tr 14/18px 偏圆润「手帐」，wb 10/14px 更利落。

## 5. 从 wb 一并采纳的用色纪律

1. **一个强调色**：橡果棕只表示「活着 / 正在发生」（运行点、焦点环、主按钮 hover、选中态竖条），其余全部中性灰。
2. **强调色面积上限**：单屏可见强调色面积 ≤ 3%；超出即用色错误。
3. **颜色即状态**：绿=运行/成功，红=失败，琥珀=需注意，近黑=主行动，橡果棕=可交互/激活。状态表达用「色点 + 文字」，不用大色块徽章。

## 6. 实现期吸收清单（落选原型的可取之处）

**来自 prototype-wb：**
- 卡片「分裂式运行按钮」：主命令直跑 + 右侧下拉列全部命令（G3 多命令快启的最佳表达）。
- 布局策略：上下堆叠为默认，窗口宽 ≥ 1360px 时发现区自动靠右成栏（见其 `05-layout-variants.html` 的六维对比与建议）。
- 设置页「启动预览」：直接展示 `wt.exe -d <cwd> -- pwsh -Login -NoLogo -Command <command>` 的实际生效命令行。
- 「路径一等公民」：路径/命令原文/cwd 一律等宽、可完整读取、一键复制，截断只在尾部。

**来自 prototypes-zc：**
- 每页顶部「场景切换条 + 编号标注 + 图例」的评审格式（后续页面评审沿用）。
- P2 形态页：README×配置双栏快填台（左栏渲染联动右栏表单、聚焦滚动定位）、CLI 词典 `{{param}}` 参数模板填空、端口雷达行式列表。
- 设置页 shell 卡片的解析呈现：resolved 路径 + 参数 + profile 状态一行展示，未支持 shell 的回退警告就地出现。

**tr 自身实现时需裁剪项：**
- 设置页超出 F7 的部分降级或移除：「启动时恢复上次视图」「界面语言切换」「启动时检查更新」「大批量暂停阈值可配」（需求定为常量 500）等，保留外观（主题）与信息密度即可。
- 「关闭窗口驻留托盘」在设置页标注为 P2，实现期不进 MVP。

## 7. 移植验收点

- [ ] 浅色主题下整屏无「米黄/牛皮纸」感：分隔线、次级文字与 wb 页面并排对照色温一致。
- [ ] 主按钮、侧栏选中项为近黑实底；橡果棕仅出现在：运行状态点、焦点环、主按钮 hover、选中指示。
- [ ] 单屏橡果棕（含 wash）面积目测 ≤ 3%。
- [ ] 暗色主题全站复检：主按钮为浅面深字，无一处棕实底主按钮残留。
- [ ] 画布顶部光晕在明暗两态均存在且不干扰文字对比度。
- [ ] 除上述 token 与组件规则外，页面结构、间距、交互行为与 tr 原型保持一致（`git diff` 应只涉及 tokens 层）。
