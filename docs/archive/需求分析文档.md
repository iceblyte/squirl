# 项目需求分析与竞品调研文档 (Draft v1.0)

## 一、 项目概述

* **暂定项目名称**：`DevDock` / `LocalPilot` / `OmniProject`（可后续敲定）
* **定位**：面向多技术栈开发者的**本地项目导航、状态保持与快捷启动中枢**。
* **核心价值**：解决“项目散落各处难查找”、“运行环境配置繁琐需重复记忆”、“全局工具/常用组合命令易遗忘”三大痛点，实现秒级定位、一键直达、轻量预览。

## 三、 竞品分析与参考借鉴

虽然市面上有各类效率工具，但针对“本地开发项目管理与状态化启动”这一细分场景的成熟开源/商业产品较少，主要可以参考以下几个方向：

1. **终端/启动器类（如 Raycast, Alfred, Wox, 或者是各类 Terminal 软件）**
* *优势*：全局唤醒快。
* *劣势*：缺乏项目维度的上下文（如 README、配置速览、技术栈图标、环境状态记忆）。


2. **IDE 自带的项目管理（如 VS Code Recent Projects, JetBrains Gateway）**
* *优势*：与编码深度绑定。
* *劣势*：被单一编辑器生态绑定，无法跨语言、跨 IDE 统一管理（例如同时管理 Java Maven 项目、Python uv 项目、Node 前端项目）。


3. **参考你的灵感来源项目架构**：
* **`yetone/magpie`** / **`cyberpath-HQ/orbis`** / **`thejacedev/Noteriv`**：这些现代开源工具多采用精美的 UI 设计、模块化架构、极佳的性能体验（Rust 后端），为本项目的轻量化、插件化、高颜值提供了极佳的架构参考。

## 四、 核心功能规划（MVP 到完整版）

### 1. 项目发现与归类 (Discovery & Organization)

* **路径扫描**：支持配置多个“基准根目录”（如 GitHub 专属文件夹、个人项目文件夹），递归扫描含有 `package.json`、`pyproject.toml`、`pom.xml`、`Cargo.toml`、`go.mod` 等特征文件的子目录。
* **手动导入**：支持拖拽文件夹或通过文件对话框手动添加。
* **标签与分组**：支持自定义分组（如：AI/ML、前端、后端、工具脚本）及多标签管理。
* **技术栈识别与图标**：自动识别项目语言/框架（Python, Node, Rust, Java, Go 等），展示对应的精致图标（类似 `oh-my-posh` 的视觉风格）。
* **背景备注**：为每个项目添加卡片备注（记录“为什么克隆”、“核心功能是什么”）。

### 2. 状态化一键启动 (Smart Launcher)

* **终端选择**：支持配置并自由选择启动终端（PowerShell、Git Bash、Windows Terminal、Cmd、MacOS 默认 Terminal / iTerm2 等）。
* **智能环境记忆**：
* Python 项目：记录并自动激活 `.venv` 后再执行运行脚本。
* Node 项目：检测是否已执行过 `npm install` / `pnpm install`，可选择跳过安装步骤直接运行。


* **自定义命令模板**：允许为项目保存常用的运行命令组合。

### 3. 轻量文档与配置速览 (Quick Reader & Config Viewer)

* **README 渲染**：内置 Markdown 渲染器，直接点击即可阅读项目说明。
* **配置文件导航**：快速列出并高亮预览项目中的关键配置文件（如 `.env`、`application.yml`、`config.json` 等），支持快速查看甚至轻量修改。

### 4. 全局 CLI 命令与组合中心 (Global Command Vault)

* **工具雷达**：记录全局命令（如 `pi`、`dsh`、`codex`），提供简要说明与用法。
* **参数组合（Snippet）**：支持带参数的常用组合命令一键复制或直接在终端中执行（如 `dsh deploy xxx`）。

### 5. 插件生态与跨端同步 (Plugins & Sync)

* **插件架构**：核心轻量，通过插件系统扩展功能。
* **跨设备同步**：初期通过 Git 仓库或云端存储配置文件（JSON/SQLite 数据库备份），实现多台电脑项目配置的一键同步。

## 五、 技术栈与分发策略建议

* **核心框架**：**Tauri 2.x + React + TypeScript + Tailwind CSS**
* *原因*：相比 Electron，Tauri 内存占用极低（几十 MB 级别），启动速度极快，完全满足你“主打启动速度快、内存占用低”的要求；前端配合 React + Tailwind 可以做出极具科技感、类似 `oh-my-posh` 或现代 AI 客户端的高颜值 UI。
* *替代方案评估*：Rust + GPUI 性能虽然极致，但生态和 UI 组件库还在早期，用 Tauri + React 开发效率更高，且能完美驾驭各种炫酷的 UI 效果。


* **跨平台支持**：Windows、macOS、Linux 三端原生打包。
* **包管理器分发**：
* Windows：支持 **Scoop**、Winget、Chocolatey。
* macOS / Linux：支持 **Homebrew**、Deb/RPM、AppImage。
