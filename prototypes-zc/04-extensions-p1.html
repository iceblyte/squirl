Each tab = one run_id with its own ring buffer. Batch stop walks the registry and reaps every group (3s grace each). Engine already supported parallelism in MVP — this is a UI-layer addition only (附录 A #6).

Stop all built-in runs?

3 running commands will be stopped — each process group gets SIGTERM then SIGKILL after a 3s grace period. External terminal windows are not affected.
