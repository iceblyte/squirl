Squirl — UI 设计风格与原型草图

本地项目台账与一键启动中枢 · Tauri 2 + React + Tailwind + shadcn/ui。 本页是风格提案与线框草图（非最终原型），包含：调研结论、设计令牌、组件样式、核心页面线框与扩展功能缩略。 UI 文案按需求 F8 使用英文，标注说明用中文。

风格定位一句话：「暗色橡木工作台」——近黑暖灰画布 + 细边框卡片 + 琥珀橡果点缀， 像 Raycast 一样克制，像 Win11 原生应用一样安分；路径、命令、日志一律等宽字体，让「命令行事实」成为视觉主角。
01 · Research

调研结论：同类产品设计语言

按你的注意事项联网调研了两个指定产品与市面主流同类产品，提炼可借鉴点如下。

EC

ElegantClipboard

Tauri 2 + React 19 + shadcn/ui + Tailwind 4
  • 同技术栈直接参考：与 Squirl 选型完全一致，组件做法可平移
  • Win11 现代 Fluent 气质：圆角卡片、柔和主题色、状态徽章
  • Mica/Acrylic 窗口材质 + 明暗跟随系统（材质列为可选增强，三端 WebView 渲染有差异）
  • 列表卡片 + 来源图标 + 「已失效」类状态标识的心智模型
M

magpie (usemagpie.ai)

Go · 菜单栏应用 + Web UI + TUI
  • Linear/Vercel 式开发者美学：单色底、1px 低对比细边框、大量留白
  • 等宽字体点缀（CLI/路径），克制的单一点缀色
  • 「Small, careful, out of the way」——与 Squirl 轻量定位同气质
  • 明暗双主题、点击弹出可搜索列表的交互范式
R

Raycast

启动器 · 键盘优先
  • 近黑深色画布（#07080a 蓝调）为开发者工具默认底色
  • 命令面板 + 可搜索下拉是「项目/命令快启」的成熟交互
  • 状态点、快捷键提示（kbd 徽章）等微细节
JT

JetBrains Toolbox / Dev Home

项目启动器/管理器同品类
  • 项目卡片网格 + 快速搜索的台账主界面范式（Toolbox）
  • 工具箱式「最近使用」排序与一键打开
  • Dev Home（已停产）的模块化仪表盘只作布局参考
02 · Color

色彩系统（暗色优先 + 亮色变体）
