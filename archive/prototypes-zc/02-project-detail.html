2 External mode

↗ Launched in Windows Terminal × pwsh at the command's cwd. The window stays open after the command ends so errors never flash away.
Process ownership
The terminal owns this process. Squirl only updates last_run_at and counts the launch — no exit code, no state machine, and quitting Squirl never touches it.
Launch record
run_id 7f3a… · adapter wt+pwsh · args: wt -d <cwd> -- pwsh -Login -NoLogo -Command <cmd> · written to app log before spawn (DR-12)

AC3: click → terminal window visible ≤ 2s. Saving still works via the persistent Save button.

  1. 1外部模式（默认）：Run 按钮用 ↗ 标识「跳出应用」；模拟器 × shell 组合唤起，命令直传 + 保持窗口打开（附录 A #4/#8）
  2. 2外部模式右栏：无日志面板；明示进程归属终端、不记退出码、应用退出不影响；launch record 保证「点了没反应」可回溯
