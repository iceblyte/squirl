Squirl 原型总览

本地项目台账与一键启动中枢 · Tauri 2 + React + Tailwind + shadcn/ui · 「暗色橡木工作台」设计语言（琥珀橡果 #F0A832 · 纯色细边框）。 每页顶部有场景切换条，可点击切换同一界面的不同状态；浮层对话框按 Esc 可关闭。
